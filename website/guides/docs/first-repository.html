Open, clone or create a project

Launch GitTurtle and open Projects. Choose an existing Git repository folder on your computer, including a linked worktree. GitTurtle remembers it in recent projects. If the app opens a previous session, use the project hub or the + in the tab strip to open another repository.

  • Clone takes a repository URL or local source, a parent folder, and a name for the destination. Start the clone when these are correct.
  • Create takes a parent folder, a project name and an initial branch. Use a new or empty destination folder. A newly created repository has no history until its first commit.
  • Passing a path to gitturtle /path/to/repository hands off to the running instance to open or focus that repository in a tab. On macOS, you can also drop a repository folder onto the Dock icon or open gitturtle://open links. See the platform guides for starting a local build.

Inspect your first change

  1. In History, select a commit. Its author, message, parents and changed files appear in the inspector.
  2. Open a changed file to enter Compare. Use Back to history to return to the same commit and scroll position.
  3. Open Working Changes to see what differs between your checkout, the index and the last commit. If both lists are empty, edit a file in your editor and return to GitTurtle. Stage and commit the change when you are ready.

Set your Git identity

Open Settings for the displayed repository. Enter the Git name and email you want this project to use, then choose Save repository identity. If your repository already has the intended identity, you can keep it.

Keep your projects together

Turn on Show the project list in Settings to keep projects in a left-hand pane. Use + in its header to make a group, and use the row menu to move or rename entries. Project names and groups live in GitTurtle’s settings and leave folder paths intact.

Open up to eight repositories or linked worktrees in tabs. Workspaces lets you pin a repository or save related tabs together. Each linked worktree keeps its own commit draft.
