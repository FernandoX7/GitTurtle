Third-party components

Upstream libraries, fonts, palette adaptations and test fixtures retain their own licenses. The project’s third-party notices identify the components, their terms and their source records. Paths in that document refer to the source checkout.

The artwork, theme and font notices include the original terms for Lucide and Feather icons, the adapted color palettes, DejaVu Sans Mono and IBM Plex Sans. GitTurtle’s turtle mark and control artwork are project assets. The website uses Manrope under the SIL Open Font License.

Notices in your build

The packager collects the dependency inventory for the target and lockfile used to build the app. It preserves license texts, patch notices and the required source archives. On macOS, look inside GitTurtle.app/Contents/Resources/licenses. On Linux, look in $XDG_DATA_HOME/gitturtle/licenses, normally ~/.local/share/gitturtle/licenses.

Use the notices supplied with the exact package you’re redistributing. Local development packages can include a REVIEW_REQUIRED.md file identifying outstanding notices. The distribution packager requires its notice check to pass.
