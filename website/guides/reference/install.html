Getting the source

The guides start with a Git clone because the packager records the commit in your app. Each guide includes the clone command, the dependencies for that system and the steps to open a repository. The first build downloads the locked Rust dependencies.

GitTurtle currently ships as source. For package availability and desktop coverage, see release and platform status. Already running GitTurtle? Open your first repository.
