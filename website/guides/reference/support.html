Start with the task

  • Install GitTurtle on macOS, Arch, Omarchy or Ubuntu and verify the build.
  • Open a repository and follow a commit into a file comparison.
  • Review worktrees and recovery options if something unexpected happened in Git.
  • Check platform coverage for your operating system and architecture.

Linux setup problems

The executable reports a missing library.
Install the runtime packages in the Ubuntu or Arch and Omarchy guide, including a working Vulkan driver for your GPU as well as the Vulkan loader. AV1 image previews optionally load libdav1d.so.7 at runtime and are not required to start GitTurtle.
The folder picker fails.
The picker needs the session D-Bus service xdg-desktop-portal and a FileChooser backend for your desktop. Install the matching backend and log out and back in if the old service is still running. You can open a repository directly with ~/.local/bin/gitturtle /absolute/path/to/repository.
An update needs to be rolled back.
Let active Git work finish and quit the app. If the installer saved a previous installation, the command below restores it and preserves preferences and drafts.
python3 "${XDG_DATA_HOME:-$HOME/.local/share}/gitturtle/install.py" --rollback

Report a bug or request a feature

Open About GitTurtle from the app menu or command palette and select Copy bug diagnostics. It records build, display and appearance information. Add your OS version, what you were trying to do, the expected result, what happened, and a short series of steps someone can repeat. A small disposable repository works well for examples.

Open the GitTurtle repository and choose Issues. Search existing reports, then select New issue and the bug or feature-request form. For a usage question, explain which guide and step you tried. Remove credentials, private repository paths and private source from anything you share.

Report a security issue privately

In the repository’s Security → Advisories area, choose Report a vulnerability. Include the affected commit, OS, impact and a sanitized example. Use private reporting for security details. Security fixes target the latest source on main.
