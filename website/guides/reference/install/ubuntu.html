Prepare the desktop

Use Ubuntu 24.04 LTS on x86-64 with a working Wayland or X11 session. These packages are for Ubuntu GNOME. Keep your GPU’s driver installed. If you use another desktop, use its corresponding portal backend.

sudo apt-get update
sudo apt-get install -y --no-install-recommends \
  git openssh-client ca-certificates python3 desktop-file-utils xdg-utils \
  libxcb1 libxkbcommon0 libxkbcommon-x11-0 libwayland-client0 libwayland-cursor0 \
  libwayland-egl1 libfontconfig1 fontconfig fonts-dejavu-core libdav1d7 \
  libvulkan1 mesa-vulkan-drivers libegl1 libgl1 libgl1-mesa-dri \
  xdg-desktop-portal xdg-desktop-portal-gnome xdg-desktop-portal-gtk

Ubuntu provides libdav1d7 through its Universe repository. This shared AV1 decoder is required to launch GitTurtle.

Install build dependencies

sudo apt-get install -y --no-install-recommends \
  build-essential clang cmake pkg-config curl \
  libfontconfig-dev libwayland-dev libxkbcommon-x11-dev libx11-xcb-dev \
  libssl-dev libzstd-dev libvulkan-dev libdav1d-dev python3-pil

Install Rust through rustup if needed. The checkout selects Rust 1.99.0. Leave SYSTEM_DEPS_* environment variables unset so the build links Ubuntu’s decoder.

Clone, package and install

git clone https://github.com/FernandoX7/GitTurtle.git
cd GitTurtle
rustup show active-toolchain
./scripts/package-linux.sh
python3 dist/gitturtle-linux-x86_64/install.py

Run the installer as your regular user. It verifies the bundle and installs the executable under ~/.local/bin with a desktop launcher.

Launch and verify

"$HOME/.local/bin/gitturtle" --build-info
gtk-launch com.gitturtle.GitTurtle

You can also launch GitTurtle from the applications menu. Choose a local repository in Projects. If the folder picker does not open, follow Linux troubleshooting. See desktop coverage or installation for other platforms.
