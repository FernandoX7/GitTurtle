Install the build tools

On Omarchy, the desktop already supplies the graphics, font and windowing libraries. Add the tools used by GitTurtle’s build and packager.

sudo pacman -S --needed rustup python-pillow cmake

On another Arch installation, also install the following packages, the Vulkan driver for your GPU and a FileChooser portal backend for your desktop. For example, GNOME uses xdg-desktop-portal-gnome.

sudo pacman -S --needed git base-devel clang pkgconf desktop-file-utils \
  fontconfig wayland libxkbcommon-x11 libx11 libxcb openssl zstd \
  vulkan-icd-loader dav1d xdg-desktop-portal

Clone and build

git clone https://github.com/FernandoX7/GitTurtle.git
cd GitTurtle
rustup show active-toolchain
./scripts/package-linux.sh

The checkout selects Rust 1.100.0. The packager builds the optimized app for the architecture of this machine. Keep dav1d installed after the build because the executable links to its shared library.

Install and launch

python3 dist/gitturtle-linux-$(uname -m)/install.py
"$HOME/.local/bin/gitturtle" --build-info

Run the installer as your regular user. It checks the bundle and installs the app, icons and launcher. Open GitTurtle in the applications menu, then open a local repository. You can also pass its path to ~/.local/bin/gitturtle.

On your Omarchy desktop

The first launch follows the desktop’s theme and monospace font. Tile or float the native Wayland window in Hyprland. Press Ctrl + Q to quit. Explore Omarchy integration or check tested platforms.

For a missing library or file picker, see Linux troubleshooting. Other systems have their own installation guides.
