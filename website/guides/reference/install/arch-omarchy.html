Install the build tools

On Omarchy, the desktop already supplies the graphics, font and windowing libraries. Add the tools used by GitTurtle’s build and packager.

sudo pacman -S --needed rustup python-pillow cmake

On another Arch installation, also install the following packages, the Vulkan driver for your GPU and a FileChooser portal backend for your desktop. For example, GNOME uses xdg-desktop-portal-gnome. Add dav1d if you want AV1 image previews.

sudo pacman -S --needed git base-devel clang pkgconf desktop-file-utils \
  fontconfig wayland libxkbcommon-x11 libx11 libxcb openssl zstd \
  vulkan-icd-loader xdg-desktop-portal

Clone and build

git clone https://github.com/FernandoX7/GitTurtle.git
cd GitTurtle
rustup show active-toolchain
./scripts/package-linux.sh

The checkout selects Rust 1.100.0. The packager builds the optimized app for the architecture of this machine. AV1 image decoding loads libdav1d.so.7 dynamically inside a confined helper when dav1d is installed, so it is not required to launch GitTurtle.

Install and launch

python3 dist/gitturtle-linux-$(uname -m)/install.py
"$HOME/.local/bin/gitturtle" --build-info

Run the installer as your regular user. It checks the bundle and installs the app, icons and launcher. Open GitTurtle in the applications menu, then open a local repository. Passing a repository path to ~/.local/bin/gitturtle while GitTurtle is running opens or focuses it in a tab.

On your Omarchy desktop

The first launch follows your Omarchy theme and monospace font across Omarchy 3.x and 4.x layouts. Tile down to narrow Hyprland splits (460×480 minimum) or float the native Wayland window. Press Ctrl + Q to quit. Explore Omarchy integration or check tested platforms.

For a missing library or file picker, see Linux troubleshooting. Other systems have their own installation guides.
