Prepare your Mac

Use an Apple Silicon Mac, Python 3.11 or later, Git, Rust through rustup and full Xcode 26 or later. Open Xcode once to finish setup. In Xcode’s settings, select its Command Line Tools and install the Metal Toolchain component.

uname -m
python3 --version
xcodebuild -version
xcrun metal --version

The first command should print arm64. The packager builds for Apple Silicon only.

Clone the project

git clone https://github.com/FernandoX7/GitTurtle.git
cd GitTurtle
rustup show active-toolchain

Run these commands from your development folder. Inside the clone, rustup selects the project’s Rust 1.99.0 toolchain. Keep the checkout and its lockfile together.

Build and open the app

./scripts/package-macos.sh
open dist/GitTurtle.app

The packager compiles the release executable, adds the app icon and license files, then signs the bundle locally. This development app uses an ad-hoc signature and has no notarization. In Projects, open a local Git repository or linked worktree.

Check the build

codesign --verify --deep --strict dist/GitTurtle.app
dist/GitTurtle.app/Contents/MacOS/gitturtle --build-info

If Metal cannot be found, finish installing the Metal Toolchain in the selected Xcode and check xcrun metal --version again. Continue to your first repository, get help or choose another platform.
