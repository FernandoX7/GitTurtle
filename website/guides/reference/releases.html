Desktop coverage

Coverage below reflects the project’s November 2026 records.

  • Apple Silicon macOS. The project builds and tests on macOS and packages on macOS 26. The newest theme picker and custom-theme interactions still await a native Mac check.
  • Omarchy on x86-64. Omarchy 4.0 has recorded Wayland installation, launch, history, file-picker, desktop font, live theme and window-scaling checks. Omarchy 4.5 on x86-64 and other Arch desktops await a recorded desktop check.
  • Omarchy on AArch64. An M2 Pro MacBook Pro running Omarchy 4.5 has exercised a local build and a CI-built archive, including first launch, history, staging, a commit and image and Markdown previews.
  • Ubuntu 24.04 on x86-64. A clean build and user-local installation have been checked. A full physical GNOME desktop pass is pending.

What a local build contains

macOS produces a locally ad-hoc-signed .app without notarization. Linux produces an unsigned user-local bundle with an installer, checksums and license files. The installer checks the package before replacing local files.

Successful Linux CI release jobs retain their checked archive for seven days for testing. Public release packages have a separate publication process. To identify a build you already have, open About GitTurtle or run the executable with --build-info.
