Desktop coverage

Coverage below reflects the project’s November 2026 records.

  • Apple Silicon macOS. The project builds and tests on macOS and packages on macOS 26. The newest theme picker and custom-theme interactions still await a native Mac check.
  • Omarchy on x86-64. On an AMD laptop running Omarchy 4.5, the CI-built archive installed and launched on Wayland. Checks covered 23 stock themes, the desktop font, tiled and floating windows, scale 2, copy and paste, and the folder picker. Fractional scales of 1.25 and 1.5 were checked on Omarchy 4.0. Other Arch desktops still await a recorded check.
  • Omarchy on AArch64. An M2 Pro MacBook Pro running Omarchy 4.5 has exercised local release builds and a CI-built archive across first launch, history, collapsible search filters, staging, commits, custom themes, image and Markdown previews, and the offline pull-request review panel (latest clean release captures on November 23).
  • Ubuntu 24.04 on x86-64. A clean build and user-local installation have been checked. A full physical GNOME desktop pass is pending.

What a local build contains

macOS produces a locally ad-hoc-signed .app without notarization. Linux produces an unsigned user-local bundle with an installer, checksums and license files; local .deb packaging and Flatpak manifest recipes are also prepared in the repository for future distribution. The installer checks the package before replacing local files, and AV1 image previews load libdav1d.so.7 dynamically when available.

Successful Linux CI release jobs retain their checked archive for seven days for testing. Public release packages have a separate publication process. To identify a build you already have, open About GitTurtle or run the executable with --build-info.
