BUILT FOR BIGGER PROJECTS

More worktrees.
Less waiting.

GitTurtle started with Fernando’s own projects: 60 GB across many worktrees. Waiting for repositories to load and commits to open kept breaking his flow. He built GitTurtle to make those everyday moments feel quick again.

FIRST-CLASS OMARCHY SUPPORT

On Omarchy, it follows your desktop.

On an Omarchy desktop, GitTurtle follows your setup from the first launch. It needs no Omarchy patch or theme template: it reads your current theme’s colors itself, hand-written and installed themes included, and never writes them. Since version 4.5, Omarchy supports Apple Silicon MacBooks natively, and GitTurtle’s Linux work is done and checked on one: an M2 Pro MacBook Pro running Omarchy 4.5.

01 /

Your theme, live

A first launch selects the Omarchy theme, which takes its colors from your current Omarchy theme. omarchy theme set retints the open window, with colors adjusted where needed so text and diffs stay readable.

02 /

Your font

Code uses your Omarchy monospace font, and omarchy font set changes it in the open window. Theme and font can each be changed in Settings.

03 /

Your keys and tools

Omarchy’s Super+C, Super+V, Super+X and Super+A work in GitTurtle’s text, and Super+C also copies a selected commit’s hash or a file’s path. With no editor chosen in Settings, Open repository in editor opens your Omarchy editor, and Open repository in terminal opens your default terminal.

04 /

At home in Hyprland

A native Wayland client that works tiled or floating and keeps Omarchy’s default window opacity. Hyprland draws no title bar, so quit with Ctrl+Q or close the window with your compositor binding.

⌘

Keyboard first

Reach every command from the palette and any tracked file from Quick Open. macOS gets a native menu bar; Linux gets a Menu at the top left of the window, one press of F10 away.

A profile for each identity

Save named Git profiles with their author and signing settings, and apply one to a repository after reviewing exactly what it will change.

Keep your projects close

Keep up to eight repository and worktree tabs open, and save them as named workspaces. Create and remove linked worktrees through a review.

Your Git, at your direction

Browsing stays local and read-only and never fetches. Writes and network requests start only when you ask, and Git keeps your hooks, signing and credential helpers.

Native, and built to stay fast

Built with Rust and GPUI, GitTurtle draws its own native window: no Electron, no web view and no AI features. Repository reads, diffs, parsing and image decoding run off the UI thread, and it works with the Git you already have installed.

macOS

Apple Silicon

Build a local app with Rust, Git, and Xcode 26 or later. It is ad-hoc signed and isn’t notarized, and the packaging script does not build for Intel Macs.

macOS build guide ↗

Arch and Omarchy

x86-64 · AArch64

Omarchy already ships the libraries GitTurtle needs: add three build tools, then package and install. The same steps work on an Apple Silicon MacBook running Omarchy; another Arch system needs a few more packages first.

Arch and Omarchy guide ↗

Ubuntu 24.04

x86-64

Install the runtime and build dependencies with apt, then package. The installer runs without sudo and installs the bundle under your home directory.

Ubuntu build guide ↗

Linux needs a Wayland or X11 desktop with working graphics drivers, and its bundle is a local, unsigned build, not a distribution package. Not every desktop has been checked yet: see what has been checked on each system and the Linux limits before relying on a workflow.
