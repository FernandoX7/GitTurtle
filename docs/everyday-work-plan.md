## Invariants

- Passive refresh, history and comparisons remain local and read-only. Explicit Git writes are serialized once, preserve configured hooks/filters/signing, and never silently retry uncertain outcomes.
- Mutation tests use disposable repositories and local remotes. Preserve unrelated working changes and linked-worktree identities.
- Keep expensive Git reads, diffs, parsing, image work and preference writes off the UI thread. Preserve bounded caches/queues, virtualization, cancellation and generation checks.
- Keep frequent actions visible and selection-specific actions beside their target. Progressively disclose advanced choices; preserve the existing application structure and turtle artwork, including light/dark/clear macOS appearances.
- Finish conflict handling before exposing dependent recovery operations. Hosting dashboards, issues, terminals/editors, AI features and elaborate interactive rewriting remain out of scope.
