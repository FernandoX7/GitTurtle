# Recovery and rewritten-series native cases

Create fresh fixtures outside observed repositories with `python3 scripts/create-recovery-rewrite-fixtures.py /tmp/gitturtle-recovery-rewrite-UNIQUE`. `fixture.json` records canonical paths, initial index stages, source hash, original/base identities and exact expected draft text. The remote is a disposable local bare repository. The native QA coordinator owns launches, application state backup/restoration and process termination.

1. Open `conflict-drafts`, choose Working Changes and `story.txt`, then Edit result. Replace the result with `draft_text` from the fixture manifest. Wait for **Recovery draft saved locally**. Confirm `git ls-files --stage` still equals the manifest and the working file SHA-256 remains unchanged. Ordinary recovery saving must not write either file or index.
2. Quit normally, reopen the same worktree, and select the conflict. Inspect the matching-source explanation and click **Restore saved draft**. Copy the entire result and compare its UTF-8 bytes with `draft_text`. Confirm Continue has not run.
3. Edit the result again, wait for Saved, record the running executable PID and terminate that process. Relaunch the same exact installed build. Restore and compare exact text again. Edits still marked Saving have not yet received a durability confirmation and are not the forced-termination checkpoint.
4. Close the app and externally replace `story.txt` with `External edit must survive\n`. Reopen and select the conflict. Restore must be disabled; **Copy saved text** must still return the saved draft. Confirm the external bytes and `:unrelated.txt` remain unchanged. Saved drafts must remain accessible after an explicit Abort and from other repositories.
5. Open `rewrite-series`, current branch menu → Edit local commits, base `HEAD~3`, Load commits. Reword the first commit and drop the third; acknowledge locally known shared history, review and start. Use Continue to open the native message editor. Enter `rebase_message_draft`, wait for Saved, close/quit/restart, use Continue again, Restore saved message, and compare exact text. Continue remains a separate reviewed write. Changing the staged index externally must disable recovery of the old message while retaining Copy saved text.
6. Finish the rebase. The local remote must still equal `original_tip`. Open **Review rewritten series**. Inspect old/new IDs, changed message, dropped row, both original/rewritten file lists, a selected file's patch and literal source, and Back to series. Close and reopen to verify the original capture survives restart. This initial fixture has separate files, so moving kept commits up/down also exercises correspondence without conflicts.
7. In series review, select remote `origin`, branch `main` and explicitly check the destination. Verify the dialog names the bare remote path, complete expected old and new IDs, and one branch. Cancel must leave the remote unchanged. Recheck, confirm **Publish with exact lease**, then verify the bare remote points to the reviewed new tip. Ordinary Push remains available separately.
8. For a movement refusal, recreate a fresh fixture/rewrite, prepare publication, then create/update a competing commit in the disposable bare remote before confirming. Publication must refuse, preserve the competing tip, and require another remote review. Core fixtures additionally cover local movement, changed push URL, pre-receive rejection, cancellation before writing and cancellation after a post-receive update (uncertain outcome).

Inspect the Saved drafts browser at minimum size and enlarged text; Copy, Retry save and Discard must have full hover/focus states. Save failures must retain editor text. Restore does not stage, continue, publish, or rewrite Git templates. Native evidence must identify the exercised build; unit/process fixtures are not native UI evidence.
