## Limitations

No live provider or real Keychain unlock, expired account, security key, or configured signing identity was exercised. Local fixtures test helper/askpass/signing failures and cancellation. Hosted CI, Linux runtime, Intel/older Macs and older macOS were unavailable; workflow configuration is not a claim of hosted execution. No dynamic-type/text-size control is provided by the current GPUI app. [Liquid Glass](liquid-glass-investigation.md) remains an explicitly documented experiment with an opaque production fallback; no glass rendering-cost claim is made.
