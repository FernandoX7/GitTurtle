# Native accessibility

GitTurtle’s current milestone includes VoiceOver, ordinary keyboard navigation and the available macOS display settings. Earlier dated milestone exclusions do not limit current work. Implementation and automated checks below are separate from the coordinator’s build-specific native evidence.

## Native semantics

The app uses the pinned GPUI Kit and AccessKit bridge. Custom controls need explicit stable IDs, roles and readable labels; drawing text is insufficient. In this toolkit version, anonymous text and `StyledText` do not create accessible nodes. Rendered Markdown therefore provides bounded readable prose, heading levels, code text, linearized table rows, image descriptions and separate Before/After documents. Exact Source remains available, and link buttons are separately reachable. PDF and model controls name their side, page or camera action; checked state is reserved for actual toggles.

History commits, changed files and working entries expose selected state, with exactly one current row reported as the active descendant of the focused list. Commit labels include subject, author, short identity and merge-parent count. Working multiselection retains all selected states while only the keyboard cursor owns active focus. The navigator is a tree with nesting and folder expansion state; Up/Down/Home/End skip section headings, Right expands or enters a folder, Left collapses or returns to its parent, Enter/Space activates, and Shift-F10 opens branch actions. Scope activation remains explicit. Warm repository tabs retain the cursor.

The command palette keeps input focus in its query while exposing a polite status node containing the selected command, position and disabled reason. Moving among results does not steal text input. Operation failures and input validation use assertive alerts; completion notices, conflict position/storage state and explicit document-navigation results use polite status nodes. Continuous rendering progress has live announcements disabled to avoid repeated speech during camera motion. The portable `a11y_synthetic_children` hook sets existing parent-node live properties; it does not create an unbounded status history.

Git-write confirmation titles and consequences, authentication prompt text and SSH host-verification guidance are readable nodes. Secret inputs retain their password content type; their values are never copied into accessibility labels. Conflict side choices name the actual side and distinguish block-draft edits from reviewed whole-file replacement/staging.

## Toolkit patch

The pinned `gpui-base` Button previously prevented disabled activation but omitted AccessKit’s disabled flag. The focused [vendored patch](../vendor/gpui-base/GITTURTLE-PATCH.md) adds that flag while delegating the original rendering and interaction behavior, retaining Apache-2.0 notices and dependency versions. The actual rendered-node regression checks role, label, disabled metadata, absence of disabled click actions and selected/unselected Tab metadata. Tab roles map existing selected presentation to native selected state; ordinary buttons do not acquire selected or pressed semantics. The focus-trap wrapper also forwards its accessible role, metadata and synthetic children, and marks Dialog/AlertDialog roles modal. Its previous omission could leave the focused dialog host absent from the tree and produce window-level fallback focus. A wrapped-node regression covers named dialogs and generic groups. Native traversal must still verify containment, restored focus and discovery of unavailable controls.

Persistent presentation selection and semantic toggle state are separate toolkit properties. Apply `.toggled` only to real switches or modes, and explicit tab/selected roles for repository tabs. An action such as Fit or Reset must not be announced as an unchecked toggle merely because it is unselected visually.

## Display preferences

On macOS, startup and foreground activation read the public `NSWorkspace` display preferences on the main thread. Reduce Motion updates the toolkit policy and pauses custom GIF playback on the current frame. First/Previous/Next remain usable; Play is unavailable while Reduce Motion is enabled. Merely disabling Reduce Motion does not silently resume playback. The app does not change system settings. A display-setting change is applied by the next foreground activation; no live AppKit notification observer is installed.

Increase Contrast and Reduce Transparency are available to the read-only inspection bridge but do not select another app palette. Principal surfaces are opaque. Native validation must observe actual contrast, transparency, hover, selection and focus behavior under those settings; the presence of the OS getters does not establish compliance. Independent interface/code sizes, both densities and all ten app themes remain part of the current visual matrix. Linux uses the portable semantic controls; the macOS settings bridge is conditional and no Linux desktop window pass is implied.

## Verification

`cargo test --locked -p gitturtle native_accessibility` exercises bounded navigator traversal and rendered button accessibility metadata. `cargo test --locked -p gitturtle reduced_motion_pause` verifies that pausing keeps the current GIF frame until explicit resume. These are model and toolkit tests, not VoiceOver evidence.

The native owner must record the exercised binary/source, OS, initial settings and restoration. Traverse Projects, repository tabs, branch folders, History/files, Working Changes, comparison and Find, conflicts, Settings, command palette, Git confirmations and GitHub forms with VoiceOver and keyboard input. Verify spoken names/roles/states, current-row movement without whole-window repetition, text editing, modal containment and restored focus. Trigger a recoverable failure and completion notice; confirm each is announced once without polling noise. Inspect readable Markdown and PDF text alternatives, image absence, page/zoom controls, model toggles and errors. Exercise Reduce Motion before startup and after foreground return; record actual Increase Contrast/Reduce Transparency behavior. Use disposable repositories for mutation tests and a separately authorized disposable hosted repository for GitHub writes.

Native acceptance covers minimum and wide window sizes, both densities, and ten themes. Actual VoiceOver, settings, native mutation and package results belong in the active milestone record; unexecuted combinations remain explicit.

## Primary guidance

Apple’s [accessibility design guidance](https://developer.apple.com/design/human-interface-guidelines/accessibility/) and [VoiceOver guidance](https://developer.apple.com/design/human-interface-guidelines/voiceover/) support readable labels, navigable order and equivalent custom-control behavior. The implementation uses the public [Reduce Motion property](https://developer.apple.com/documentation/appkit/nsworkspace/accessibilitydisplayshouldreducemotion), [Increase Contrast property](https://developer.apple.com/documentation/appkit/nsworkspace/accessibilitydisplayshouldincreasecontrast), and [Reduce Transparency property](https://developer.apple.com/documentation/appkit/nsworkspace/accessibilitydisplayshouldreducetransparency). [Apple’s VoiceOver evaluation criteria](https://developer.apple.com/help/app-store-connect/manage-app-accessibility/voiceover-evaluation-criteria) inform the native workflow checks; this document makes no certification or App Store declaration.
