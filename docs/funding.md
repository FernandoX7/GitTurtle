# Funding

[Sponsor GitTurtle's development through FernandoX7 on GitHub Sponsors](https://github.com/sponsors/FernandoX7).
The live profile accepts custom one-time and monthly contributions.

Sponsorship supports maintenance, bug fixes, documentation and testing on macOS
and Linux. It does not promise particular features, priority support or response
times. Testing, documentation and code contributions are also welcome through
the [contribution guide](../CONTRIBUTING.md).

## Maintaining the destination

Keep the funding file, README and support guide aligned if the destination
changes, and verify that a replacement can receive contributions before linking
it. Recheck the repository button after changing the default-branch funding
configuration. Account enrollment, payout details, tax information and account
security remain owner-controlled and do not belong in this repository or its
issues. No private account-dashboard screenshot is stored as project evidence.
