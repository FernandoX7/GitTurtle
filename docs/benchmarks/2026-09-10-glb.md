# GLB retained geometry and raster measurements — September 10, 2026

On the exercised Apple M4 Max, the 65,536-triangle synthetic torus decoded in
2.121 ms at p50 and 2.224 ms at p95; a retained-scene 720-pixel solid frame took
5.646 / 5.752 ms. These are individual CPU operation timings, not native frame
latency or a speedup comparison. No previous GLB implementation was measured.

## Method and results

Each fixture runs in a separate process, in the table order below. The
[`bench_model` harness](../../crates/preview/examples/bench_model.rs) reads the
input once before timing, so captured bytes are resident. Every row decodes a
fresh scene without an application cache, fits an isometric camera outside the
timed intervals, then separately renders fresh 360-pixel solid, 720-pixel solid
and 720-pixel all-edge wireframe outputs. Rendering uses that row's retained
geometry. Output destruction is outside the intervals and only one rendered
frame is retained at a time.

Each file preserves one first attempt, three warmups and all 30 measured rows.
The first attempt is not a cold-filesystem result. Filesystem reads, camera
fitting, destruction, application scheduling/cache lookup, native input, GPUI,
GPU upload and OS presentation are excluded. No attempts failed or were removed.
All 170 rows and the printed summaries were checked; table values below are
rounded from the raw samples.

Every cell is **p50 / p95 / maximum in milliseconds**, using nearest-rank
percentiles over the 30 measured rows only.

The [fixture README](../../crates/preview/tests/fixtures/models/glb/README.md)
records source, license and geometry expectations. BoxInterleaved is an unchanged
Cesium CC-BY-4.0 sample; Avocado is an unchanged Microsoft CC0-1.0 sample from
Khronos. Avocado's larger input includes appearance bytes that the geometry path
does not decode. Its input size therefore does not predict expanded geometry or
texture-rendering cost. The arch, torus and existing OBJ tetrahedron were authored
for GitTurtle. OBJ is an existing-format reference, not an equivalent-work
performance comparison. No private models or private paths are included.

`scene_retained_bytes` accounts for the immutable scene, not peak process memory,
source bytes, temporary parser allocations or raster buffers. A 720-pixel RGBA
frame is 2,073,600 bytes; solid rendering also uses 4,147,200 bytes of depth values.
Those sizes are allocation accounting, not measured process/GPU memory.

## Reproduction

From the same source revision:

```sh
cargo build --release --locked -p gitturtle-preview --example bench_model
python3 scripts/create-glb-preview-fixtures.py /tmp/gitturtle-glb-bench-fixture > /tmp/gitturtle-glb-bench-fixture.json
target/release/examples/bench_model crates/preview/tests/fixtures/models/glb/assembly-before.glb 30 3 > /tmp/assembly-before.tsv
target/release/examples/bench_model crates/preview/tests/fixtures/models/glb/BoxInterleaved.glb 30 3 > /tmp/BoxInterleaved.tsv
target/release/examples/bench_model crates/preview/tests/fixtures/models/glb/Avocado.glb 30 3 > /tmp/Avocado.tsv
target/release/examples/bench_model /tmp/gitturtle-glb-bench-fixture/dense-torus.glb 30 3 > /tmp/dense-torus.tsv
target/release/examples/bench_model crates/preview/tests/fixtures/models/tetra.obj 30 3 > /tmp/tetra-obj.tsv
```

Keep outputs outside the watched fixture. The checked-in TSVs replace only the
two local model/executable path comments with portable labels; timing rows,
warmups, first attempts, other comments and summaries remain unchanged.
