## Measurement boundary

Elapsed means workflow creation to the last job completion. Execution span means
first job start to last job completion; it is an observed span, not a computed
job-dependency critical path. Runner time sums job intervals, including overlap;
it is neither elapsed time nor billed minutes. Queue means creation to first job
start. Each named run is one observation, with different source, coverage and
queue conditions. These samples do not establish a performance distribution or p95.

### Four budget timeouts

Every lane's budget preparation returned `save=false` with the fixed reason
`cache budget preparation unavailable` and never reached `after_source_pruning`;
both save registrations per lane reported `outcome=skipped`, and the post-run cache
inventory contained no Rust entries. The corrected accounting did supply the
missing measurements. After local-package cleanup and excluding the projected
removable registry sources, the payloads were Linux debug **5,875,984,057**, macOS
debug **3,904,050,616**, Linux release **3,078,669,022** and macOS release
**2,811,687,766** projected bytes against the **1,610,612,736-byte** ceiling.
Removable registry sources accounted for **1,326,555,506** bytes (46,525 entries)
in every lane, and the retained downloads (current `*-sys` sources, archives and
index) for **457,410,050** bytes.

- Linux debug: 4 dependency cleanups removed 60,148,030 bytes in total; budget work
  **96.298314s**.
- macOS debug: 7 dependency cleanups removed 45,651,163 bytes; budget work
  **90.064234s**.
- Linux release: 4 dependency cleanups removed 0 bytes; budget work **92.258710s**.
- macOS release: 8 dependency cleanups removed 0 bytes; budget work **97.517451s**.

The coordinator's read-only analysis attributes this outcome to four defects rather
than one. The 90-second deadline also governed the mandatory verification scans, so
an exhausted eviction loop failed instead of falling back to a downloads-only save.
Package-scoped `cargo clean` without `--profile` never touched release artifacts,
and the release lanes compile with `--target <triple>`, so their outputs live under
`target/<triple>/release/`, which a clean without `--target` also leaves intact.
The eviction ranking matched every path component against every target name, so
dependencies with a test or example target named `debug` were credited with the
whole debug tree and the evicted packages were small. Finally, even a correct
eight-package eviction (about 1.0 GB debug and 0.5 GB release on a local build of
the same workspace) cannot bring these payloads under 1.5 GiB. Locally,
`zstd -3 --long=30` compressed a CI-like debug payload 6.34× and a release payload
4.95× (downloads 1.21×), which projects roughly 3.3 GB of compressed archives per
cache generation against the repository's 10 GB quota (0.2 GB in use, all historical
CodeQL entries). These local ratios are sizing evidence, not hosted archive sizes.
Diagnostic artifacts `10424421543`, `10424590075`, `10423702861` and `10424340700`
(SHA-256 `bda1db62…`, `74f78920…`, `f821a93a…`, `6ebe5b8d…`) and all twelve job logs
are retained; each compilation lane's runner time includes about 95 seconds of
failed budget work. **This run also produced zero compiled-cache seeds.**
