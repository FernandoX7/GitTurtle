## Reproduce the measured boundary

From the repository root at the recorded current source, run:

```sh
python3 scripts/bench-graph-layout.py \
  --baseline-ref 0c8eaec31ae9fdbc7fe7f98c5822cc0561f96ad4 \
  --warmups 20 --samples 100 \
  --output /tmp/gitturtle-consistency-20260909/milestone-graph-raw.json
```

The output directory must already exist. The [existing helper](../../scripts/bench-graph-layout.py) extracts the model/layout region of `graph.rs`, supplies a minimal owned commit model, and compiles a dependency-free harness. The successful cancellation path includes an `AtomicU64` acquire load on every row. Fixture construction and one prepared layout for clone measurements occur outside timed samples.

| Equal fixture | Timed work |
| --- | --- |
| Linear, 20,000 commits | Full layout and output destruction; each commit has one parent, including the final parent outside the loaded history. |
| Wide, 8,001 commits / 21 lanes | A merge with 20 parents outside the loaded history followed by 8,000 linear commits; full layout and output destruction. |
| Clone 60 visible rows, for each fixture | Clone/drop rows 1 through 60 from a prepared layout, repeated 200 times per timed batch. The reported sample is batch time divided by 200. Shared immutable edge buffers remain shared. |

This excludes Git reads, worker queueing, graph budget preflight, cancellation failure paths, fallback selection, element construction, tessellation, paint, GPU completion, OS presentation, and native navigation. The synthetic wide graph does not represent the cost of every real merge topology. Clone batches are small algorithm operations; their per-frame averages are not frame render times. This single sequential run is descriptive and does not estimate a confidence interval or establish a performance regression threshold.
