Keyboard route (all scenarios)
------------------------------
Ctrl+comma opens Settings. The Your themes card is brought on screen with the mouse wheel over the
page (Tab moves focus to off-screen Settings controls without scrolling); after that the pointer rests
on the status bar and is not moved again until Delete, so no pointer event repaints a frame. Tab x28
from the title bar's Menu button reaches New theme…; Space activates it. Dialog Tab order observed:
Name, Base, (Keep colors, Replace colors while the base question shows), then per row hex field and
colour picker (row k: hex at Tab 2+2k, picker 3+2k), the Readability list (44), Reset to base (45),
Cancel (46), Save (47), wrapping to Name. Base menu: Space opens, Down moves (the first Down
highlights nothing, group labels are skipped), Return chooses. Ctrl+A selects a field's text.
Light flows save with Return on Save and cancel with Return on Cancel; dark flows save with Return
in Name and cancel with Escape. Delete…: Space opens the confirmation, whose keyboard focus must be on
Cancel; Tab moves to Delete theme and a second Tab must stay inside the alert; Return on Cancel and
Escape close it; Return on Delete theme deletes. The deletefocus-* scenarios launch with the flow's
saved theme already in the store and active, reach Delete… by Tab x28 + Tab x2, and delete once per
launch. Hex fields are read exactly as they are after typing, with the caret at the end and no Home
press (cd563f6's driver pressed Home before every read because its 70 px field scrolled the leading #
out of view; D2 checks that the 78 px field never does). Return in a hex field: the field interior must
match the frame where the lowercase text was typed directly; the frame typed before Return is the
contrasting reference. The scrollbar track is painted in the canvas colour (the app's scrollbar track
colour), so what shows at rest is the 6 px thumb in the border colour inside the reserved 16 px column;
D1 reads that column and lists every other colour found in it.

moved the wide layout's Tab-to-the-last-row step after the base question, since scrolling the column to
its end and back leaves the Canvas row at the top of the viewport rather than at its resting y.

the hex field's left border is 24 px left of cd563f6's (16 px reserved track + 8 px wider field), the
