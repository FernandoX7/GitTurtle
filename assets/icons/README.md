# GitTurtle icons

Original SVG artwork created for this project. No third-party icon assets or GitKraken artwork are included.

Icons use a 24 × 24 view box with rounded 1.65-unit white strokes. Render at 16–18 logical pixels for normal controls and use GPUI's SVG color to tint them. White makes raster-mask tinting reliable without depending on CSS `currentColor` interpretation. Keep aspect ratio and provide accessible labels on the containing control. The standalone turtle mark is in `../turtle-mark.svg`.
